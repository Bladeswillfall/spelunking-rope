# Terminology

Use these terms consistently in code and documentation unless a later design decision changes them.

- **Rope:** structural/load-bearing line used for climbing, rappelling, traversal, hauling, or mechanical routing.
- **Guide cord / guide line:** lighter line primarily used for navigation and route marking.
- **Piton:** lightweight expedition anchor, typically attached to a surface.
- **Anchor:** reusable/general attachment fixture for structural rope.
- **Node:** logical point in a rope network.
- **Span:** rope section connecting two adjacent nodes.
- **Sheave / pulley:** explicit routing node over which rope changes direction.
- **Winch:** device that pays out or reels in rope.
- **Rope network:** connected graph of rope nodes and spans sharing topology/state.
- **Attachment reference:** persistent logical reference to whatever a node is attached to.
- **Traversal attachment:** temporary player/entity relationship to a rope path.
